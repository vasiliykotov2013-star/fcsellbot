# ⚡ ForsCraft Alert — 24/7 Cloud Bot & Scraper

Автономный облачный мониторинг донатов и покупок с сайта `https://forscraft.net` с мгновенными оповещениями в Telegram бот `@fcsell_bot`.

## 🌟 Возможности
- **24/7 в облаке**: Работает непрерывно, даже когда ваш домашний компьютер полностью выключен.
- **Два режима облачного запуска**:
  1. **GitHub Actions** (автоматически каждые 5 минут): Не требует серверов, работает прямо из этого репозитория.
  2. **Render.com / Railway.app** (потоковый демон с веб-сервером): Опрос каждые 8 секунд.
- **Накопительная история**: Все покупки за предыдущие и последующие дни сохраняются в `cloud_history.json`.
- **Команды Telegram**:
  - `/today` — статистика и список покупок за сегодняшний день.
  - `/stats` — сводка доходов по серверам (Survival, Anarchy, SkyBlock, Duels, Other).
  - `/all` — список последних покупок за все дни.
  - `/start` — подписка на уведомления.

## 🚀 Запуск в облаке за 1 минуту

### Вариант 1: GitHub Actions (Уже настроен в репозитории!)
1. Репозиторий содержит `.github/workflows/bot_runner.yml`.
2. После пуша в GitHub перейдите во вкладку **Actions** в репозитории.
3. GitHub автоматически опрашивает `forscraft.net` каждые 5 минут и присылает все покупки в ваш Telegram.

### Вариант 2: Бесплатный хостинг Render.com (Постоянный 24/7 онлайн)
1. Зайдите на [render.com](https://render.com) и войдите через GitHub.
2. Нажмите **New +** -> **Web Service**.
3. Выберите этот репозиторий `forscraft-bot`.
4. Render автоматически применит файл `render.yaml`.
5. Нажмите **Deploy** — бот работает без перерывов 24/7!
